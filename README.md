## 📋 Sobre o Projeto

Este projeto consiste em uma *Landing Page* (Página de Destino) desenvolvida para um negócio local no nicho de barbearia premium. A arquitetura foi pensada para maximizar a experiência do usuário (UX) e facilitar o contato direto, utilizando chamadas para ação (CTAs) estratégicas integradas à API do WhatsApp.

Como um projeto de **desenvolvimento web**, ele demonstra a aplicação de boas práticas de marcação, estilização moderna e interatividade voltada para acessibilidade.

## ✨ Funcionalidades Principais

- **Design Responsivo (Mobile-First):** Layout 100% fluido, otimizado para celulares, tablets e desktops.
- **Integração com WhatsApp:** Botões de CTA que redirecionam o usuário diretamente para o aplicativo com mensagens pré-configuradas.
- **UI/UX Premium:** Paleta de cores *Dark Theme* com contrastes em dourado, transmitindo sofisticação.
- **Acessibilidade e SEO:** Marcação semântica profunda, atributos `aria-label` injetados dinamicamente e meta tags Open Graph para compartilhamento em redes sociais.
- **Manipulação de DOM:** Atualização automática do ano de *copyright* via JavaScript Vanilla.

## 🛠️ Tecnologias e Ferramentas

O desenvolvimento foi realizado utilizando tecnologias puras (Vanilla), sem dependência de bibliotecas externas pesadas:

- **HTML5:** Estruturação semântica avançada.
- **CSS3:** Flexbox, CSS Grid, Media Queries e Custom Properties (Variáveis CSS).
- **JavaScript (ES6+):** Lógica simples e eficiente para manipulação do DOM.
- **Google Fonts:** Utilização da família tipográfica *Inter* para alta legibilidade.
